# Portafolio de Datos - Álvaro Márquez

Este repositorio contiene el código fuente de mi portafolio profesional como Analista de Datos, diseñado para destacar mis proyectos, habilidades técnicas y certificaciones recientes.

## Tecnologías Usadas
- **HTML5:** Estructura de la página web.
- **Tailwind CSS:** Framework de CSS utilizado (vía CDN) para un diseño minimalista, responsivo y moderno.
- **FontAwesome:** Íconos vectoriales.
- **GitHub Pages:** Alojamiento gratuito y despliegue continuo de la página estática.
