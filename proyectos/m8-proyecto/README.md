# Proyecto M8 - Machine Learning

Este repositorio contiene la solución al desafío del Módulo 8 del Bootcamp en Fundamentos de Ciencia de Datos.

## Descripción del Proyecto

El objetivo principal es implementar un modelo de Machine Learning capaz de clasificar o predecir basándose en el dataset proporcionado. 

### Fases del Proyecto:
1. **Análisis Exploratorio de Datos (EDA):** Limpieza, manejo de valores nulos y visualización de distribuciones.
2. **Ingeniería de Características:** Transformación de variables categóricas, escalado de datos.
3. **Modelamiento:** Entrenamiento de algoritmos utilizando Scikit-Learn.
4. **Evaluación:** Uso de métricas como Accuracy, Precision, Recall y F1-Score para determinar el mejor modelo.
